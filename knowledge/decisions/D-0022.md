# D-0022: Magazines stack to eight by load; the screen fills exactly one

Rusty, 2026-09-23: "Can you make the magazines in ranged weapons mod
stackable? At least like kind magazines"; "Max stack size for mags should be
8". D-0013 forced the stack size to one because two magazines with different
loads cannot share a stack.

Accepted: `MagazineItem` stacks to eight and "like kind" is the game's own
stacking rule, the same item with the same components, so the same load, name
and dye. Nothing is added to decide likeness: an emptied magazine has its
contents component removed (as `Magazines.setContents` already did), so it
stacks with new ones; a part magazine sits alone. `R` takes one magazine off
the chosen slot (`removeItem(slot, 1)`); the outgoing magazine goes into that
slot when it is empty, as before, else wherever it fits by vanilla's
`placeItemBackInInventory`, which merges like stacks and drops only with the
inventory full. The magazine screen fills exactly one magazine: a write to a
stack would load every magazine in it from one handful of rounds, a dupe.
So `MagazineMenu.open` sets the rest of a stack aside first (onto like stacks
other than the hand's, then a free slot) and refuses with a message when they
do not fit, and every server-side write (`writeBack`, the Fill button) sets
aside again, dropping at the feet as the last resort, because a number-key
swap over the locked hand slot or a pickup can put a stack in the hand while
the screen is open.

Rejected: filling a whole stack at once (a slot drag cannot mean "one round
into each of eight"); refusing the screen for any stack (a right-click on the
stack you carry is the natural way in); a domain change (which magazine goes
in is by slot, and a stack is one slot, so `MagazineChoice` is unchanged).

Verified by the gametests `magazinesStackToEightByLoadTakeADyeAndKnowTheirFamily`,
`theReloadKeyTakesOneMagazineOfAStackAndTheOldOneFindsRoom` and
`theMagazineScreenFillsOneMagazineOfAStackAndSetsTheRestAside`.
