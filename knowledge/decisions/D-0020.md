# D-0020 — Craft the shotgun pump in a vertical column

Rusty requested fixing the shotgun recipe with creative license, then releasing
the revolver and fix together. The pump's horizontal plank-stick-plank recipe
matched all eleven Macaw's Roofs wooden top-roof recipes (issue #1).

Rotate those same ingredients into one vertical column: plank, stick, plank.
This preserves the two-plank/one-stick cost and wood-around-a-rod construction,
while freeing the horizontal row for roofs. The assembled shotgun, existing
items and recipe-book unlock remain unchanged. Blueprints stays the sole recipe
source; datagen writes the new pattern and the real recipe manager checks it.

The explicit release go covers Ranged Weapons Mod 2.5.0 with D-0019, this fix,
and its already-prepared D-0018 dependency packaging. The existing required
Metals and Materials installation is retained in the pack.
