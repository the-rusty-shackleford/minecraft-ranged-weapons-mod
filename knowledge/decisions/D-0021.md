# D-0021: Lower-right ammo panel clears gear controls

Rusty reported the gun HUD overlapping Backpacks+ and Quick Slot, and chose the
lower-right area after declining an upper-left placement. The old anchor was
the same as Quick Slot; a renamed magazine could also run beyond the screen.

Keep the panel above the bottom quickslot row and below the compact backpack
mount row. Its width adapts to the space outside the vanilla hotbar with an
8-pixel right inset. Preserve magazine styling while abbreviating long labels;
compress count spacing, then scale only the count when a narrow GUI requires it.
The reload bar uses the same panel width. The full-width G gesture opens storage
controls into this otherwise free strip. An optional client adapter reads Backpacks+'
public, server-synced gear snapshot to detect that layout and raise the ammo panel
above it while browsing. Compact gear controls already sit higher and keep the normal
ammo position. Backpacks+ 0.2.1 is compile-only and is never bundled or required;
the adapter loads only when that mod is present.

The client-only gate uses the actual Backpacks+ and Quick Slot jars, survival
equipment and key bindings in a disposable Minecraft client with Complementary
Unbound shaders. Capture normal and minimum GUI widths, both main hands, gear
browsing and a reload. Inspect captures after actual GUI rendering; server-only
tests cannot verify overlap. The harness and fixtures are excluded from the jar.
