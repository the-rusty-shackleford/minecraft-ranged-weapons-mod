# D-0009 — A one-handed gun is held out level, by an arm pose added to the game's enum

**Decision**: `HumanoidModel.ArmPose` gains a value, `RANGEDWEAPONSMOD_PISTOL`,
through the loader's enum extension (`META-INF/enumextensions.json`,
`enumExtensions` in the mod entry, the `EnumProxy` in `client/ArmPoses`).
Its transformer sets the holding arm level with the eyes and turns it with
the head, as the game's bow pose does for two arms. `ClientSetup` returns
it from the one-handed guns' client extension; the two-handed guns keep
the crossbow hold. The pistol's third-person transform was re-calibrated
by photograph for the raised arm's frame.

**Why**: With no pose, an item in hand hangs at the side, and a pistol
hanging at the hip is not how anyone holds a pistol; Rusty asked for the
arm out, "like every shooter ever", with Another Gun Mod's revolver as the
picture to match (photographed in the booth as a reference, nothing of it
read). The game's own poses that raise an arm are two-handed (bow,
crossbow) or wrong (spyglass, brush); a value of our own is the loader's
supported way to add one. Custom values cannot be constructed in code --
the enum is extended at class load from the JSON, and `EnumProxy` is how
the parameters reach the constructor.

**Alternatives rejected**: *The bow pose* — raises both arms. *A render
event rewriting the arm after posing* — fights the model every frame, and
the pose is not a property of the item then.

**Links**: `src/main/java/com/nfx/rangedweaponsmod/client/ArmPoses.java`,
`src/main/resources/META-INF/enumextensions.json`, `client/ClientSetup.java`,
`devtools/art/build.py` (`PISTOL_DISPLAY`), the booth's `booth-pistol-third-side`
and `booth-reference-*` frames.
