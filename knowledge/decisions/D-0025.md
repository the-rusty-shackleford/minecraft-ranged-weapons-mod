# D-0025: A round's case is a copper nugget, not an ingot

Rusty, 2026-09-28: "for crafting rounds in the ranged weapons mod, instead of whole ingots
they should use nuggets".

Accepted:

- **The medium round is an iron nugget over gunpowder over a copper nugget**, still eight
  to the craft: `Blueprints.ROUND_RECIPE` takes `#c:nuggets/copper` (`COPPER_NUGGET`) where
  it took `#c:ingots/copper`. The copper ingot is no longer an ingredient of anything ours.
- **The nugget is the common tag's, not ours.** Vanilla has no copper nugget; Create's
  (`create:copper_nugget`, Create 6.0.10) fills `c:nuggets/copper` in the pack, so the
  recipe resolves there. The gametest server has no Create: the gametest mod registers a
  stand-in `rangedweaponsmod_gametest:copper_nugget` and puts it in the tag in its own
  datapack, which is never shipped, so the crafting gametests still find every tag filled
  and craft every blueprint.
- The other rounds already took nuggets. The slug keeps its whole iron ingot unless Rusty
  says otherwise ("one heavy round, four to the ingot").
- No payload or menu changes: recipes are data the server sends, so no protocol bump.
